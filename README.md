# Juk Browser

Кроссплатформенный браузер с русским интерфейсом на Electron/Chromium. Поддерживает вкладки, историю, закладки, загрузки, инкогнито, масштаб, стартовую страницу с частыми сайтами, менеджер паролей с автозаполнением, картинку в картинке, индикатор звука на вкладках и восстановление сессии. Настройки, история, закладки, загрузки и пароли открываются отдельными вкладками (`juk://settings`, `juk://history`, `juk://bookmarks`, `juk://downloads`, `juk://passwords`) — через меню «☰», `Ctrl+H` / `Ctrl+J` или по запросу в адресной строке.

Дополнительно: прокрутка полосы вкладок колёсиком мыши и список всех вкладок (кнопка «⌄» или `Ctrl+Shift+A`), недавно закрытые вкладки на странице истории, повтор прерванных загрузок, статус-бар с адресом ссылки под курсором, запросы разрешений сайтов (камера, микрофон, геолокация, уведомления) с подтверждением, защита от попап-спама и подтверждение открытия внешних протоколов.

Восстановление сессии ленивое: фоновые вкладки не загружаются до первой активации, а после аварийного завершения вкладки не загружаются вовсе до клика (защита от циклических падений). Есть проверка орфографии (ru/en) с вариантами в контекстном меню, диалог HTTP Basic/Digest-авторизации, панель «Сведения о сайте» (иконка слева в адресной строке: защищённость соединения, cookies, выданные разрешения), запоминание масштаба для каждого сайта с индикатором в адресной строке, контекстное меню закладок на панели, превью вкладки при наведении и полная клавиатурная навигация в меню (стрелки, `Enter`, `Esc`).

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm start
```

Проверка синтаксиса:

```bash
npm run check
```

## Сборка

```bash
npm run dist:win    # NSIS .exe и portable
npm run dist:mac    # .dmg и .zip (выполнять на macOS)
npm run dist:linux  # .AppImage и .deb (выполнять на Linux)
```

Результаты создаются в `dist/`. Для неподписанных локальных сборок система может показать предупреждение издателя. Кроссплатформенные нативные форматы рекомендуется собирать на соответствующей ОС.

Данные профиля хранятся в каталоге `userData/Juk Browser`: `browser-data.json`. Инкогнито использует временный раздел памяти и не записывает историю, загрузки или cookies после закрытия окна.

## Горячие клавиши

- `Ctrl+T` / `Ctrl+W` / `Ctrl+Shift+T` — новая вкладка / закрыть / восстановить закрытую
- `Ctrl+Tab` и `Ctrl+Shift+Tab` — переключение вкладок; `Ctrl+1…8` — вкладка по номеру, `Ctrl+9` — последняя; `Ctrl+Shift+A` — список всех вкладок
- `Ctrl+N` / `Ctrl+Shift+N` — новое окно / окно инкогнито
- `Ctrl+L` (или `Ctrl+K`) — адресная строка
- `Ctrl+H` — история, `Ctrl+J` — загрузки, `Ctrl+D` — добавить закладку, `Ctrl+F` — поиск по странице, `F3` / `Shift+F3` — следующее / предыдущее совпадение
- `Ctrl+R` / `F5` — обновить, `Ctrl+Shift+R` — обновить без кэша, `Esc` — остановить загрузку, `Alt+←` / `Alt+→` — назад / вперёд, `Alt+Home` — домашняя страница
- `Ctrl+U` — код страницы, `Ctrl+S` — сохранить страницу, `F11` — полноэкранный режим
- `Ctrl` + `+` / `-` / `0` — масштаб, `Ctrl+P` — печать, `Ctrl+Shift+I` / `F12` — инструменты разработчика
